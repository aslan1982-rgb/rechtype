# RechType

Локальная голосовая диктовка для Windows: одно нажатие `Ctrl+Space` начинает запись, второе останавливает её, распознаёт речь и вставляет готовый текст в активное поле.

> Проект работает полностью локально. Аудио, распознанный текст и пользовательские исправления не отправляются во внешние API.

## Возможности

- качественное распознавание русской речи через GigaAM v3 e2e RNNT;
- автоматический резервный переход на Vosk, если GigaAM недоступна;
- запись любой длительности с разбиением по паузам на фрагменты до 20 секунд;
- таймер и индикатор уровня звука во время записи;
- глобальная горячая клавиша Windows;
- прямая Unicode-вставка и резервная вставка через буфер обмена;
- локальная история аудио и явных пользовательских исправлений;
- автономная работа без `ffmpeg`, облака и API-ключей.

## Готовая сборка

1. Скачайте архив из раздела **Releases**.
2. Распакуйте его в обычную папку с достаточным свободным местом.
3. Запустите `RechType.exe`.
4. Разрешите Windows доступ к микрофону, если появится запрос.
5. Нажмите `Ctrl+Space`, продиктуйте текст и нажмите `Ctrl+Space` ещё раз.

Первое распознавание после запуска может занять немного больше времени: модель загружается в оперативную память при первом обращении.

## Требования

- Windows 10/11 x64;
- минимум 8 ГБ RAM, рекомендуется 16 ГБ;
- микрофон;
- около 2 ГБ свободного места для распакованной полной сборки.

## Запуск из исходников

Нужны Git и Python 3.11 x64. Рекомендуется использовать путь без кириллицы для виртуального окружения и сборки PyTorch.

```powershell
git clone https://github.com/aslan1982-rgb/rechtype.git
cd rechtype
py -3.11 -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install --upgrade pip
python -m pip install -r requirements.txt
python tools\download_models.py
python run.py
```

Скрипт загрузит модели в локальную папку `models/`. Эти большие файлы намеренно исключены из Git.

## Управление

| Действие | Результат |
|---|---|
| Первое нажатие `Ctrl+Space` | Начать запись и показать таймер |
| Второе нажатие `Ctrl+Space` | Остановить запись, распознать и вставить текст |
| ПКМ по значку в трее | Открыть настройки и действия |
| «Исправить последнюю диктовку» | Сохранить проверенный текст для будущего обучения |
| «Папка обучающих данных» | Открыть локальную историю и исправления |

## Приватность и локальные данные

По умолчанию история хранится в:

```text
%LOCALAPPDATA%\RechType\learning
```

Для каждой диктовки сохраняются исходный WAV и результат распознавания. После явного исправления добавляется `corrected.txt`, а подтверждённая пара включается в `training-manifest.tsv`. Эта папка приватная и никогда не должна добавляться в GitHub Issues или в репозиторий без предварительного удаления личных данных.

## Проверка качества

```powershell
python tools\benchmark_asr.py `
  --audio C:\path\to\test.wav `
  --reference C:\path\to\reference.txt `
  --engine gigaam `
  --model-dir models\gigaam `
  --output work\gigaam-transcript.txt
```

На локальной контрольной записи длительностью 280,64 секунды GigaAM v3 показала WER 31,68% против 47,61% у Vosk small ru. Контрольная запись и эталонный текст приватны и в репозиторий не входят; числа приведены только как ориентир для сравнения версий на одном и том же материале.
