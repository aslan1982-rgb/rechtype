RechType v0.0.2 — транскрибация аудио и видео

Новое:
- главное окно для транскрибации существующих файлов;
- выбор файла через диалог или перетаскивание в окно;
- поддержка аудиодорожек в распространённых аудио- и видеоконтейнерах;
- встроенное офлайн-декодирование без отдельного ffmpeg.exe;
- просмотр, копирование и сохранение результата в TXT;
- один экземпляр приложения: повторный запуск открывает уже работающее окно;
- параметр --background для тихого запуска вместе с Windows.

Сохранено:
- диктовка по Ctrl+Space;
- локальное распознавание через GigaAM v3 e2e RNNT с автоматическим резервом Vosk;
- локальная история диктовок и пользовательских исправлений;
- отсутствие облачных API и отправки аудио в сеть.

Примечания:
- первая транскрибация после запуска может быть медленнее из-за загрузки модели;
- распознавание длинных файлов зависит от мощности процессора и длительности записи;
- сборка Windows не имеет цифровой подписи, поэтому SmartScreen может показать предупреждение.
