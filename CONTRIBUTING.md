# Как помочь проекту

Спасибо за интерес к RechType.

## Перед началом

- Не прикладывайте личные аудиозаписи, историю диктовки или содержимое `%LOCALAPPDATA%\RechType\learning` к публичным задачам.
- Для воспроизведения ошибок используйте короткий искусственный пример без персональных данных.
- Для крупных изменений сначала создайте обсуждение или Issue, чтобы согласовать направление.

## Локальная разработка

Проект поддерживает Python 3.11 x64 и Windows 10/11.

```powershell
py -3.11 -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install --upgrade pip
python -m pip install -r requirements-test.txt
python -m pytest -q
```

Полные зависимости и модели нужны только для ручной проверки распознавания или сборки приложения.

## Pull Request

- Добавьте или обновите тесты для изменённого поведения.
- Убедитесь, что `python -m pytest -q` проходит полностью.
- Не добавляйте модели, архивы сборок, аудио и локальные конфиги.
- Кратко опишите пользовательский эффект и способ проверки.

Отправляя вклад, вы соглашаетесь распространять его на условиях лицензии проекта GPL-3.0.
