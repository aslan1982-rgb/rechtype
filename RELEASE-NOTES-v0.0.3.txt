RechType v0.0.3
================

Что нового
----------

- Потоковая диктовка по горячей клавише продолжает работать через GigaAM v3
  e2e RNNT с автоматическим резервным переходом на Vosk.
- Перед распознаванием выбранного аудио- или видеофайла можно переключаться
  между GigaAM Multilingual Large 600M и GigaAM v3 e2e RNNT.
- Для файлов по умолчанию используется более точная GigaAM Multilingual Large
  600M.

Загрузка Large-модели
---------------------

При первом выборе GigaAM Multilingual Large 600M приложение один раз скачает
около 2,18 ГиБ в:

%LOCALAPPDATA%\RechType\models\gigaam

После завершения загрузки модель и распознавание файлов работают офлайн. Аудио,
видео и распознанный текст не отправляются во внешние API.

Состав релиза и требования
--------------------------

Базовый архив содержит GigaAM v3 e2e RNNT и Vosk, но не содержит Large-модель:
её raw checkpoint превышает лимит GitHub в 2 ГиБ на один release asset.

Для диктовки и GigaAM v3 e2e RNNT достаточно прежних системных требований. Для
GigaAM Multilingual Large 600M рекомендуется компьютер с 32 ГБ оперативной
памяти и дополнительно около 2,18 ГиБ свободного места.
