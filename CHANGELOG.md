# История изменений

Все заметные изменения проекта документируются в этом файле.

## 0.0.2

- Добавлено главное окно для выбора и транскрибации локальных аудио- и видеофайлов.
- Добавлено встроенное декодирование медиаконтейнеров через PyAV без внешнего `ffmpeg.exe`.
- Результат можно просмотреть, скопировать или сохранить в TXT.
- Декодирование и распознавание файлов выполняются вне GUI-потока.
- Повторный запуск открывает уже работающий экземпляр приложения.
- Добавлен скрытый режим `--background` для автозагрузки Windows.
- Импортированные медиафайлы не копируются в историю обучающих данных.

## 0.0.1

- Первый публичный выпуск RechType для Windows.
- Локальное распознавание русской речи через GigaAM v3 e2e RNNT с резервным Vosk.
- Запись запускается и останавливается повторным нажатием `Ctrl+Space`.
- Добавлены таймер, индикатор уровня звука и обработка длинных записей по фрагментам.
- Добавлены Unicode-вставка, локальная история и сохранение пользовательских исправлений.
- Работа GigaAM не требует внешнего `ffmpeg` для записанных приложением WAV-файлов.
