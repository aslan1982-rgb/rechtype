# Политика безопасности

## Поддерживаемая версия

Исправления безопасности выпускаются только для последней опубликованной версии.

## Как сообщить об уязвимости

Не публикуйте уязвимость и реальные пользовательские записи в открытом Issue. Используйте приватное сообщение владельцу репозитория или GitHub Private Vulnerability Reporting, если оно включено.

Укажите версию приложения, версию Windows, ожидаемое и фактическое поведение, а также минимальные шаги воспроизведения без персональных данных. Не прикладывайте токены, пароли, аудиозаписи и содержимое локальной истории.
